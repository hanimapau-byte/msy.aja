1. Pendahuluan & Apa itu Kabel LAN?

Pengenalan Dasar Jaringan Ethernet & Jenis Kabel

Kabel LAN (Local Area Network) atau sering disebut Kabel Ethernet adalah media transmisi fisik berbentuk kabel yang digunakan untuk menghubungkan berbagai perangkat komputer, komputer ke router, maupun dua perangkat komputer secara langsung (*peer-to-peer*) dalam cakupan area lokal.

Kabel ini menyalurkan sinyal berupa paket data elektronik dengan kecepatan tinggi, kestabilan koneksi yang jauh lebih presisi, dan latensi lebih rendah dibandingkan koneksi nirkabel (Wi-Fi).

Fungsi Utama Kabel LAN:

  • Menghubungkan antar komputer/laptop secara lokal.
  • Berbagi data / berkas (*File Sharing*) tanpa internet.
  • Berbagi sumber daya perangkat lunak & keras (seperti Printer LAN).
  • Menghubungkan perangkat ke Modem/Router untuk akses Internet.

Kategori Utama Kabel Ethernet

UTP (Unshielded Twisted Pair)

Kabel pilin tanpa pelindung alumunium foil. Sangat populer, fleksibel, dan terjangkau untuk kebutuhan indoor / laboratorium.

STP (Shielded Twisted Pair)

Memiliki lapisan pelindung (*shield*) pembungkus tembaga guna meredam gangguan interferensi elektromagnetik eksternal (sering dipakai industri).

Standar Urutan Warna (Pinout)

Pengkabelan LAN mengacu pada 2 standar internasional: T568A dan T568B.

2. Alat & Bahan Perakitan Kabel LAN

Peralatan standar yang wajib disiapkan sebelum melakukan pemotongan dan crimping kabel

Kabel UTP / STP

Kabel inti yang berisi 8 helai kawat tembaga berpasangan terpilin dengan warna khas (Oranye, Hijau, Biru, Cokelat & Putihnya).

Tang Crimp (Crimping Tool)

Alat khusus untuk mengunci konektor RJ45 dengan kawat kabel, serta dilengkapi pisau pemotong dan pengupas jaket kabel.

Konektor RJ-45

Kepala konektor plastik transparan berisi 8 pin kuningan yang akan ditancapkan ke port Ethernet/LAN pada komputer/switch.

LAN Tester

Perangkat penguji berdaya baterai dengan 8 lampu indikator LED untuk mengecek apakah tiap pin terhubung sempurna atau tidak.

Langkah Praktis Merangkai Kabel

Langkah 1

Kupas Jaket Kabel

Kupas pelindung luar kabel sepanjang ±2 cm menggunakan pengupas tang crimping.

Langkah 2

Luruskan & Urutkan

Urai lilitan 8 kawat, luruskan dengan rapi, lalu susun sesuai skema warna (Cross/Straight).

Langkah 3

Potong & Masukkan RJ45

Potong rata ujung kawat sisa ±1.2 cm, lalu dorong kawat hingga menempel ke ujung pin RJ45.

Langkah 4

Press / Crimping

Tekan kuat tang crimp hingga pin tembaga menembus kawat dan kunci konektor dengan rapat.

4. Menghubungkan 2 Laptop & Konfigurasi IP

Langkah Konfigurasi Network Adapter pada Windows

Setelah kabel LAN tipe Crossover selesai dirangkai, colokkan masing-masing ujung kabel RJ45 ke port LAN Ethernet pada Laptop A dan Laptop B.

Agar kedua laptop dapat saling berkomunikasi, kita perlu memberikan alamat identitas lokal unik yang berada dalam subnet yang sama melalui pengaturan **IP Address Static**.

Contoh Pengaturan IP Address Target:

Laptop A (Komputer Utama):

• IP Address: 192.168.1.1

• Subnet Mask: 255.255.255.0

Laptop B (Komputer Tujuan):

• IP Address: 192.168.1.2

• Subnet Mask: 255.255.255.0

Panduan Pengaturan Windows

  1. Buka Control Panel: Tekan tombol `Win + R`, ketik `ncpa.cpl` lalu Enter untuk membuka **Network Connections**.
  2. Pilih Adapter Ethernet: Klik kanan pada opsi **Ethernet**, lalu pilih **Properties**.
  3. Atur IP Version 4: Klik dua kali pada **Internet Protocol Version 4 (TCP/IPv4)**.
  4. Pilih IP Static: Tandai opsi *"Use the following IP address"*.
  5. Isikan IP: Masukkan IP `192.168.1.1` di Laptop A, dan `192.168.1.2` di Laptop B. Tekan `Tab` agar Subnet Mask otomatis terisi `255.255.255.0`.
  6. Simpan: Klik **OK** pada seluruh jendela dialog.

5. Pengecekan Koneksi (Pengujian Ping)

Verifikasi komunikasi data antar dua laptop menggunakan Command Prompt (CMD)

Perintah Ping (Packet Internet Groper) digunakan untuk mengirimkan paket ICMP ke laptop lawan untuk memastikan jaringan telah terhubung secara fisik dan logis tanpa hambatan.

Cara Pengujian dari Laptop A (192.168.1.1):

  1. Tekan `Win + R`, ketik `cmd`, lalu tekan Enter.
  2. Ketik perintah: ping 192.168.1.2
  3. Tekan Enter dan amati balasan sinyal pada terminal.

Penjelasan Output CMD:

✅ Reply from 192.168.1.2: bytes=32 time<1ms TTL=128

Berhasil! Laptop tujuan merespons paket data dengan cepat. Koneksi LAN sempurna.

❌ Request Timed Out (RTO)

Sinyal tidak terbalas. Biasanya disebabkan oleh Windows Firewall di laptop tujuan yang masih aktif memblokir ICMP, atau susunan kabel longgar.

⚠️ Destination Host Unreachable

Komputer pengirim tidak menemukan rute IP lawan. Periksa kembali subnet mask dan konfigurasi IP.

6. Cara Transfer File / Sharing Folder

Berbagi Berkas dan Dokumen Berkecepatan Tinggi Melalui Jaringan Kabel

1

Matikan Password Protection

Buka Control Panel > Network and Sharing Center > Advanced sharing settings. Pada bagian All Networks, aktifkan "Turn off password protected sharing" agar tidak diminta password Windows saat mengakses.

2

Atur Hak Akses Sharing Folder

Klik kanan pada folder yang ingin dibagikan > Properties > tab Sharing > Klik tombol Share.... Tambahkan user Everyone, ubah Permission Level menjadi Read/Write, lalu klik Share.

3

Akses Folder dari Laptop Lawan

Di Laptop B, buka File Explorer, pada address bar ketik \\192.168.1.1 lalu tekan Enter. Seluruh berkas yang dibagikan dari Laptop A akan muncul dan siap diunduh secara instan!
