Pendahuluan: Kabel LAN / Ethernet

Kabel LAN (Local Area Network) atau dikenal juga sebagai kabel Ethernet adalah media transmisi fisik berbentuk kabel yang digunakan untuk menghubungkan berbagai perangkat jaringan (seperti komputer, laptop, router, dan switch) dalam area geografis yang terbatas.


Kabel LAN mentransmisikan sinyal data elektronik antar komputer melalui susunan kawat tembaga di dalamnya. Dalam praktikum ini, koneksi langsung antar 2 laptop (*Peer-to-Peer*) membutuhkan konfigurasi Kabel LAN tipe Cross-Over agar pin pengirim (TX) pada laptop pertama terhubung langsung ke pin penerima (RX) pada laptop kedua.

Alat-Alat & Cara Pembuatan Kabel LAN

Alat utama yang dibutuhkan dalam pembuatan kabel LAN tipe Cross-Over:

  • Kabel UTP (Unshielded Twisted Pair): Kabel berisi 8 helai kawat berwarna.
  • Konektor RJ-45: Kepala kabel modular sebagai penghubung ke port LAN.
  • Tang Crimp (Crimping Tool): Alat pemotong, pengupas, dan pemotong/pemutus pengunci konektor RJ-45.
  • LAN Tester: Alat uji untuk memverifikasi apakah seluruh pin terhubung dengan benar.

Langkah Pembuatan Kabel Cross-Over:

  1. Kupas jaket luar kabel UTP sepanjang ± 2 cm menggunakan tang crimp.
  2. Uraikan pilinan kawat dan urutkan warna kawat sesuai standar Cross-Over:
    • Ujung A (T568B): Putih Orange, Orange, Putih Hijau, Biru, Putih Biru, Hijau, Putih Cokelat, Cokelat.
    • Ujung B (T568A): Putih Hijau, Hijau, Putih Orange, Biru, Putih Biru, Orange, Putih Cokelat, Cokelat.
  3. Ratakan ujung kawat dengan memotongnya lurus menggunakan pisau tang crimp.
  4. Masukkan urutan kawat ke dalam konektor RJ-45 hingga menyentuh bagian paling ujung.
  5. Pres/crimp konektor RJ-45 menggunakan tang crimp hingga terdengar bunyi klik/terkunci.
  6. Uji kedua ujung kabel menggunakan LAN Tester. Pada tipe Cross, lampu LED indikator akan menyala secara bersilangan (1-3, 2-6, 3-1, 6-2).

Konfigurasi, Check Koneksi & Transfer File

1. Pengaturan IP Address

Sambungkan kabel LAN Cross ke port Ethernet kedua laptop. Buka Control Panel > Network and Sharing Center > Change adapter settings. Klik kanan pada Ethernet > Properties > pilih Internet Protocol Version 4 (TCP/IPv4).

Laptop 1:
IP Address: 192.168.1.1
Subnet Mask: 255.255.255.0

Laptop 2:
IP Address: 192.168.1.2
Subnet Mask: 255.255.255.0

2. Pengecekan Keterhubungan (Ping)

Buka Command Prompt (CMD) pada Laptop 1, ketikkan perintah untuk memanggil IP Laptop 2 guna memastikan kedua perangkat terhubung:

C:\Users\User> ping 192.168.1.2

# Jika Berhasil:
Reply from 192.168.1.2: bytes=32 time<1ms TTL=128

3. Cara Sharing File Antar Laptop

  1. Pilih folder yang ingin dibagikan pada Laptop 1, klik kanan > Properties.
  2. Buka tab Sharing > klik tombol Share...
  3. Pilih Everyone dari daftar dropdown, klik Add, lalu ubah Permission Level menjadi Read/Write. Klik Share.
  4. Pada Laptop 2, buka File Explorer dan ketikkan IP Laptop 1 pada address bar (contoh: \\192.168.1.1).
  5. Folder yang dibagikan akan muncul dan file siap ditransfer secara langsung dengan kecepatan tinggi!
